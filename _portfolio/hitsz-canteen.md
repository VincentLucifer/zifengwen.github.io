Java backend engineer. A WeChat mini program for cafeteria takeout and meal ordering, built on Spring Boot, with staff and dish management. Features include orders, cart, call reminders, and coupons; users can browse dishes, place orders, and pay.

- Implemented 70+ APIs independently: 45 on the admin side, 25 on the user side
- Maven multi-module split of the admin backend; Git for version control
- Redis for storage/cache latency and concurrency, plus Spring Cache to simplify cache code
