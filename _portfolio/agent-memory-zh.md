算法研究助理，哈尔滨工业大学（深圳），2026.03–2026.07。导师：刘学博教授。

针对 LLM Agent 在长时程软件工程任务中历史经验利用不足、上下文窗口受限等问题，探索长期记忆机制，并基于 SWE-bench 开展实验。

- 调研 AgeMem、G-Memory、MemGas、BMAM 等代表性工作，归纳长期记忆、共享记忆与层次化记忆设计
- 设计轨迹存储、语义检索与动态更新实验框架，支持 LLM、Memory 与 Multi-Agent 协作
- 基于 SWE-bench 搭建自动化评测，从问题解决率、推理成本与上下文利用效率等维度分析不同记忆策略
