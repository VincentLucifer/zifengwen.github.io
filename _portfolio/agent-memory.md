Research Assistant, Harbin Institute of Technology, Shenzhen, Mar. 2026 – Jul. 2026. Supervisor: Prof. Xuebo Liu.

Investigated long-term memory for LLM-based Software Engineering Agents, targeting weak reuse of past experience and limited context windows.

- Surveyed AgeMem, G-Memory, MemGas, and BMAM, covering long-term, shared, and hierarchical memory designs
- Built an experimental framework with trajectory storage, semantic retrieval, dynamic updates, and multi-agent collaboration
- Evaluated memory strategies on SWE-bench by task success rate, inference cost, and context utilisation
