Java 后端开发工程师。面向食堂外卖与订餐的微信小程序，基于 Spring Boot，支持员工与菜品管理。功能包括订单、购物车、来电提醒、优惠券等，用户可浏览菜品、下单及支付。

- 独立完成 70 余个接口：管理端 45 个，用户端 25 个
- Maven 依赖管理与聚合拆分后台系统，Git 做版本控制
- Redis 缓存加速响应与并发处理，结合 Spring Cache 简化缓存代码
